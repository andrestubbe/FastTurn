# FastTurn Philosophy — Meaning Over Raw Silence

1. **Silence is a Weak Proxy**: Humans know when a thought is incomplete before any pause begins. FastTurn combines acoustic VAD with semantic sentence parsing.
2. **Sub-Millisecond State Transitions**: Conversational responsiveness requires instantaneous state machine transitions (< 1 µs) without GC pauses.
3. **Seamless Barge-In**: Conversational flow must allow the human to interrupt the machine naturally at any point in time.
